# Mon patrimoine 💼

Mini-app web de suivi de patrimoine : enveloppes, actifs, performance, historique.

- **100 % locale** : aucune donnée n'est envoyée nulle part. Tout est stocké uniquement dans le navigateur de ton appareil — ce dépôt ne contient **aucune donnée financière**.
- **Installable** sur l'écran d'accueil (PWA) : ouvrir l'URL puis « Ajouter à l'écran d'accueil ».
- **Hors ligne** : fonctionne sans connexion grâce au service worker.
- **Import CSV Finary**, export JSON / CSV.
